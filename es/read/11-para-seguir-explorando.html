11 Para seguir explorando

Como este libro trata sobre la intersección de la línea de comandos y la ciencia de datos, muchos temas relacionados solo se han mencionado superficialmente. Las siguientes subsecciones proporcionan una lista de temas y recursos sugeridos para consultar.

11.1 La Línea de Comandos

  • The Linux Command Line: A Complete Introduction, 2nd Edition Por William E. Shotts, Jr. (No Starch Press, 2019)
  • Unix Power Tools, 3rd Edition por Jerry Peek, Shelley Powers, Tim O’Reilly, y Mike Loukides (O’Reilly Media, 2002)
  • Learning the Vi and Vim Editors, 7th Edition por Arnold Robbins, Elbert Hannah, y Linda Lamb (O’Reilly Media, 2008)

11.2 Programación de Shell

  • Classic Shell Scripting por Arnold Robbins y Nelson H.F. Beebe (O’Reilly Media, 2005)
  • Wicked Cool Shell Scripts, 2nd Edition por Dave Taylor y Brandon Perry (No Starch Press, 2017)
  • Bash Cookbook por Carl Albing JP Vossen (O’Reilly Media, 2018)
  • Nushell Book: https://www.nushell.sh/book/

11.3 Python, R y SQL

  • Learn Python 3 the Hard Way por Zed A. Shaw (Addison-Wesley Professional, 2017)
  • Python for Data Analysis, 2nd Edition por Wes McKinney (O’Reilly Media, 2017)
  • Data Science from Scratch, 2nd Edition por Joel Grus (O’Reilly Media, 2019)
  • R for Data Science por Garrett Grolemund y Hadley Wickham (O’Reilly Media, 2016)
  • R for Everyone, 2nd edition por Jared Lander (Addison-Wesley Professional, 2017)
  • Sams Teach Yourself SQL in 10 Minutes a Day, 5th Edition por Ben Forta (Sams, 2020)

11.4 APIs

  • Mining the Social Web, 3rd Edition por Matthew A. Russell y Mikhail Klassen (O’Reilly Media, 2019)
  • Data Source Handbook por Pete Warden (O’Reilly Media, 2011)

11.5 Aprendizaje Automático

  • Python Machine Learning, 3rd Edition por Sebastian Raschka y Vahid Mirjalili (Packt Publishing, 2019)
  • Pattern Recognition and Machine Learning por Christopher M. Bishop (Springer, 2006)
  • LightGBM Documentation: https://lightgbm.readthedocs.io/
  • DuckDB Documentation: https://duckdb.org/docs/
  • UMAP Documentation: https://umap-learn.readthedocs.io/
  • SmartCore (Machine Learning en Rust): https://github.com/smartcorelib/smartcore
  • Linfa (Framework de Machine Learning en Rust): https://github.com/rust-ml/linfa
  • Candle (Minimalist ML Framework for Rust por Hugging Face): https://github.com/huggingface/candle
  • Burn (Flexible Deep Learning Framework in Rust): https://github.com/tracel-ai/burn
  • NuTorch (Tensor Operations for Nushell): https://github.com/astrohackerlabs/nutorch
