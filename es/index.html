Inicio Rápido con Docker (`dsin`)

Cada pipeline, script y bloque de código del currículo está verificado para ejecutarse de forma 100% reproducible dentro del contenedor Docker autónomo kurokirasama/dsin:latest, que incluye plugins de Nushell preconfigurados, rutas de montaje de datos y herramientas de modelado.

docker run --rm -it -v "$(pwd)/Files:/data" kurokirasama/dsin:latest
