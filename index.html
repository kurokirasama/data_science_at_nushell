Quickstart with Docker (`dsin`)

Every pipeline, script, and code block in the curriculum is 100% verified to run reproducibly inside the standalone kurokirasama/dsin:latest Docker container with pre-configured Nushell plugins, dataset mount points, and modeling engines.

docker run --rm -it -v "$(pwd)/Files:/data" kurokirasama/dsin:latest

Curriculum Structure

  • Chapter 1
    Introduction
    The terminal as a scientific laboratory, the Nushell structured data paradigm, and reproducible environments.
  • Chapter 2
    Software Installation
    The standalone dsin Docker container, interactive setup, and environment verification.
  • Chapter 3
    Nushell Fundamentals and Data Structures
    Terminal introduction, shells vs. Nushell, strings, lists, records, tables, cell paths, ttt editor, and Git.
  • Chapter 4
    Programming and Creating Command-Line Tools
    Custom commands (def, export def), flags, strong typing, modules, Google Maps API, and R/Python integration.
  • Chapter 5
    Data Acquisition
    HTTP requests (http get), decompression, Excel spreadsheets (.xlsx), SQLite databases (query db), and REST APIs.
  • Chapter 6
    Data Cleaning and Transformation
    Native Nushell filtering, structural mutations, tabular reshaping, and the high-performance Polars plugin.
  • Chapter 7
    Exploratory Data Analysis and Visualization
    Descriptive statistics (math, polars summary), polyglot scripts (.R/.py), and in-terminal plotting with timg.
  • Chapter 8
    Serial and Parallel Data Pipelines
    Serial batching (each), native concurrency (par-each), and GNU parallel orchestration.
  • Chapter 9
    Polyglot Data Modeling
    Dimensionality reduction (PCA, t-SNE, UMAP), clustering (K-Means/Hierarchical/DBSCAN/PAM), regression (VW, LightGBM, DuckDB OLS), and classification including neural networks (ml-benchmark, skll, Rscript, python3 → Nushell tables).
